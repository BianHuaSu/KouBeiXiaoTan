# 口碑小探 · 外卖评价智能分析 Agent

把外卖店铺评论压成一句能落地的建议：先判断样本值不值得分析，再清洗、分类、抽方面、挖主题、交叉校验，最后输出口碑概览、红黑榜和商家改进建议。

这个项目不是“预先分析好一批结果再演示”，而是三层可分开跑的东西：

1. **本地 Demo**：`口碑小探-demo.html`，单文件、离线可开，内置一个自训练的小模型；点一家店时现场抽样、清洗、分析。
2. **专用情感模型**：`外卖情感模型/`，字符 1–4gram 哈希 + 情感词典先验 + L2 逻辑回归，导出 int8 JSON；不是 LLM，不调用在线大模型 API。
3. **网页评价抓取器**：`外卖评价抓取工具/`，用本机 Edge 登录态抓真实店铺评论，输出 CSV 和预载分析页。
4. **手机评价采集器**：`手机评价采集工具/`，安卓 ADB + 界面树（UI Automator）优先，截图 OCR 兜底，或截图文件夹批量 OCR；解决网页端只显示前几条、评价只在 App 里的问题。

## 快速开始

### 看 Demo

双击 `口碑小探-demo.html`。内置 10 家演示店用的是公开语料现场抽样，不是预分析结果；想用真实数据，走下面两种方式。

### 抓真实店铺评论（推荐）

```text
双击 外卖评价抓取工具/启动界面.bat
→ 选平台
→ 登录并保存登录态（大众点评/美团/饿了么需要）
→ 粘贴店铺页 URL
→ 开始抓取
```

抓完在 `外卖评价抓取工具/output/时间_店名/` 下得到：

- `reviews_full.csv`：评分、评论、用户、日期、平台、店铺
- `reviews_demo.csv`：只有评分和评论，可直接拖进 Demo
- `口碑小探-抓取分析.html`：这批评论的预载分析页

### 上传自己的 CSV

打开 Demo，点“上传我的评论 CSV”，支持：

- `rating,review`：1–5 星
- `label,review`：1/0 情感标签
- 每行一条评论的纯文本

上传模式至少 10 条；没有菜品字段时，菜品红黑榜会隐藏。

### 手机 App 才有全部评价怎么办

网页端只下发前 N 条，完整评价通常在手机 App。用 `手机评价采集工具/`：

```text
双击 手机评价采集工具/安装依赖.bat（只需一次）
→ 双击 启动界面.bat
→ 安卓手机开 USB 调试，数据线连电脑
→ 手机上手动登录并打开店铺评价页
→ 工具里点“检测设备”，解析方式保持“界面树（推荐）”，再点“开始采集”
```

界面树直接读 Android 系统文本节点和坐标，按日期切评价卡，用户名、标签、正文不会混在一起；页面是 WebView 时才退回“截图 OCR”。界面树默认**不截图**，边滑边读，速度优先；星级按“超预期/很棒/一般/很糟糕”标签校准成 5 / 4.5 / 2.5 / 1 的近似值。需要逐条真实半星，再勾选“截图校准星级”（每屏多约 0.6 秒）。默认滑动 320ms、每屏停等 0.35s，比原来的 600ms / 1s 更快。小米/Redmi 要自动滑动，还需在开发者选项里打开 **USB 调试（安全设置）**；不想开也可以手动滑一屏、点一次“抓当前屏（手动逐屏）”，结果会追加到同一批。

如果不想开 ADB，用“截图 OCR 导入”标签：把手机截图放进一个文件夹，批量识别成 CSV。

采到 10 条以上会自动生成 `口碑小探-手机采集.html`，双击直接看分析；也可以把 `reviews_demo.csv` 上传到主 Demo。工具只读取你手动打开、有权访问的页面，不逆向 App 接口、不破解验证码。

## 模型说明

`外卖情感模型/sentiment_model.json`：

- 字符 1–4gram signed hashing，2^19 桶，int8 权重
- 情感词典先验 + 合成增强
- 逻辑回归，否定窗口 4 字
- 语料测试：准确率 89.33%，F1 83.73%
- 外部 76 条测试集：85.5%（同源偏高，真实场景会低一些）

它是**专用小模型，不是 LLM**。手机上可以直接本地跑：`外卖情感模型/外卖情感模型-手机版.html`。

## 网页端被限制怎么办

先分清两类情况：

**网页只显示前几条、App 才有全部**

这不是抓取技术问题，是网页端只下发前 N 条，没下发的数据不在 DOM 里。路线只有三条：

1. **自己的店**：商家后台导出 / 官方开放平台 API，稳定拿全量。
2. **只做 Demo**：用 `手机评价采集工具/` 采集手机端可见评价（ADB 截图 + OCR，或截图批量 OCR），输出 CSV / 预载分析页。
3. **竞品全量**：没有授权 API 时没有合规稳定解，不建议逆向 App 签名或接口。

**一直跳验证中心 / 身份核实 / 403**

1. **人工接管**：在抓取器里点“人工接管抓取”，浏览器正常打开，你完成登录/验证并滚到评论区，工具只抽取当前页面；不破解验证码、不伪造请求。
2. **降频 + 单页**：不要并发、不要连续重跑；每次只抓一页，条数控制在 30 左右。
3. **官方导出/API**：有商家后台权限就从评价管理导出 CSV，再上传 Demo；有开放平台资质走官方接口。批量场景这条最稳。

如果人工验证后仍是“验证中心 / 身份核实 / 403”，说明账号或网络已被平台限制，继续自动抓取没有合规的稳定解，应改走官方导出或授权账号。

## 边界

- 大众点评、美团、饿了么都有登录和反爬；工具不绕过验证码，验证时由你手动完成。
- 抓取器抓的是页面当前可见评论；样本条数受页面分页限制。
- 平台改版会让选择器失效，改 `外卖评价抓取工具/scraper.py` 里的 `SELECTORS` 即可。
- 请只抓取自己店铺、已授权店铺或公开页面，并遵守平台条款。
